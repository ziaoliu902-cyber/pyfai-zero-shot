## 判读（V3 零样本在 ID22 2θ 族上 = 不可用，第 3 个独立域外证据）

- **rot 全程 0**：9/9 帧倾角解从未激活（平面解坍缩），帧间 SO(3) 增量 0.000° vs 电机真值 10.000°
  （编码器步进 10.0000±0.0001°，硬真值精度远高于判定需求）——完全失败。
- **中心钉死画布几何中心** (2068,252)=((W-1)/2,(H-1)/2)：tth0-60 六帧一字不动；tth70/80 跳到
  (1192,368)/(1184,288)（两帧互洽±8px 但仍无倾角）。物理上 2θ 臂每 +10° 中心位移≈D·sin10°
  ≈ 90mm≈1200px，迅速出画布——正是零样本"中心在画布内"假设的死区。
- **相鉴随机**：期望全 LaB6，实际 Quartz4/LaB6 2/Al2O3 3。tth10 判对 LaB6 但 D=267mm 塌缩；
  λ=0.354Å 环压缩低角 + 模块 gap 与 D2AM(0.4959Å) 同款病因。
- **D 无趋势**：523→267→647→580→554→521→560→289→302mm，与 2θ 扫描应有的 D≈const 完全矛盾。
- 与 ID28（g17/g45 rot=0 坍缩）、D2AM（Δc 中位 1385px）三点共线：**短波+离轴/出画布中心+模块
  探测器 = V3 零样本域界**。E2 扩样本：ID22 只能作族一致性参考（BM20 式 rot 模型外推路线），
  不进零样本战绩表。
