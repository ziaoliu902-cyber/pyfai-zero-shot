## 域界结论（V3 零样本能力边界，正反例齐备）

1. **中心出画布 / 大倾角 → 必败**：ID22 tth 族（真中心每步移 ~1200px 迅速出画布，V3 rot 全零）、
   ID28 g17/g45（官方单帧 GR 也崩——非我方独有，需多帧联合模型）。
   **D2AM 15 帧（接手复核：束心在画布外 800–1500px、rot2 18–50°）**。
2. **长 D·短 λ 高 q 环缺失 → D-环径简并退化**：Pilatus1M 1.58m（中心对、D 偏 3.5%）、
   mar3450。（D2AM 原列此类，接手复核后改归第 1 类：真因是束心出画布，不是 λ–D 简并。）
3. **反例澄清**：短 λ 单独不致死——Eiger9M 0.3738Å 完美；模块 gap 单独不致死——
   Pilatus6M(MX_ceria) 5×12 模块完美。协同因子（gap+短λ+特定相）才致命。
4. 主场（λ~0.7-1Å、中心在画布内、常规 D）：亚像素中心 + 0.1mm 级 D，稳定复现
   （第 9/10 套 + root 3 帧）。

## 管道备忘（E2 数据加载必带）

- ID22：focus.h5 是元数据壳（内嵌 data 全 0）；真帧 eiger_0000.h5，bitshuffle(32008)
  需先 `import hdf5plugin`。
- D2AM/halfccd：poni/npt 若引用 spline，CWD 必须在数据目录；spline 探测器 pixel1 可能 None
  （px 从 poni PixelSize 行或 spline 头读，X/Y 各向异性 ~3%）。
- halfccd/LaB6_0020 poni 无 Wavelength 字段（两文件同内容）→ 零样本不可评。
- GR.refine3() 默认连波长精修 → D-λ 简并漂移崩（D2AM 首跑教训）：束线 λ 必 fix=["wavelength"]。
- pyFAI C 层 "Overflow on dim" 警告走 stderr 且量大（67 万行/57MB）：一律 stdout/stderr 分流，
  日志只看 stdout；**永远不要整 cat 日志文件**（上下文杀手）。
