## 这张表对论文的作用

1. **跨仪器**：Pilatus / Eiger 两代、CeO2 / Al2O3 / AgBh / LaB6 四种标样；
2. **零样本**：相和几何都不给，没有一个 GT 数字进求解器；
3. **倾角验证**：Δrot 直接与 GT 对比，0.01–0.25°；
4. **诚实边界**：6 行失败都写明原因（简并 / 样条 / 低信噪 / 束在画布外），不是“挑好的报”。
