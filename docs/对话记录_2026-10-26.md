## 一、今日核心结论：v4b 的"灾难性遗忘"是**评测常数不匹配**造成的假象

同一个 base_v4b 模型，只换解码常数，全体 dist MAE：

| 解码所用常数 | dist MAE |
|---|---|
| `train_v2` 的常数 | **1311.54 mm** |
| `finetune_v1` 自己的常数 | **10.40 mm** |

→ 之前"base_v3 被遗忘 97%"的结论**不成立**，是拿 `train_v2` 的归一化常数去解 `finetune_v1` 训练的模型。

**方法论固化**：跨模型比较时，**每个模型必须用它自己 meta.json 里的 `config` 解码**；
要横向比较"同一物理量"时，必须先把各模型的输出归一化到统一常数再比（即统一常数探针）。

## 二、假象底下压着两个**真 bug**（代码级确认）

### Bug 1：合并时抄错 config → 标签越界 + 编码空间错位

`merge_ft.py`：

```python
m0 = json.load(open(os.path.join(packs[0][0], "meta.json")))  # = practice 段
meta = {"config": m0["config"], ...}                          # ← 只抄第 0 段！
```

- practice 段 `dist_range = [0.1, 1.0]`（`dhi = log10(1.0) = 0`）
- regular 段 `dist_range = [0.1, 3.0]`，实际样本到 **2.99 m**
- 归一化 `dist_n = (log10(dist) - dlo)/(dhi - dlo)*2 - 1`（`torchfai/dataset.py:45`）
  → 2.99 m 映射到 **+1.95**，**399 行（1.99%）标签越界**，且整个 dist 编码空间
  与 `base_v3`（`dist_range=[0.1,3.0]`，`dhi=0.4771`）**错开 0.4771**。

### Bug 2：微调集近距严重过采样 → 远距档无有效信号

`finetune_v1` = practice 12k + regular 8k，其中 >0.77 m 仅 **6.2%**，
而 `base_v3` 的训练集远距占比约 **24%** → 远距档梯度被淹没。

### 已核验（今天做完的一致性检查）

practice / regular / far_patch_v1 / train_v3 四者的**全部归一化相关字段完全一致**
（`poni_frac_range`、`rot1~3_range`、`binning`、`wavelength`、`detector_name`、
`beamstop_*`、`bg*`、`hot_*`、`dw_b_range`、`hump_*`、`dead_rate_range`…），
**唯一差异是 `dist_range`**。→ 说明 Bug 1 可以只靠"取并集"修正，不涉及其它通道。

差异字段（属**数据外观/难度**，非归一化）：`min_visible_peaks`（practice=6，其余=2）、
`hump_prob`（practice=0.05，其余=0.35）、`peak_counts_range`（practice 1e4~4e4，其余 3e3~3e4）。

## 三、数据血缘事实（明早直接用）

- `train_v3` = 80000 行 = `train_v2`(65000) + `hard_patch_v1/near_mix`(12000) + `hard_patch_v1/agbh_far`(3000)
  - 切分 seed=0, ratios 0.88/0.06/0.06 → train 70400 / val 4800 / **test 4800**
  - **v3 test(4800) 对 v3 无泄漏**（v3 从未在其 test 上训练）
- `far_patch_v1` = 15000 行，**AgBh 单相**，dist 0.6~3.0 m，**其行已包含在 train_v2 内**
  → 作为"远距重放"时，会与 `train_v2/test`、`train_v3/test` 重叠
  → **必须剔除泄漏行**（否则远距档对比失效：v4c 会在 train_v3 test 上多见约 900 行远距样本）
- `dataset.py` 硬约束：`assert self.shards` 且 **分片行数之和必须 == 打包行数**
  → 无法只做行级剔除后复用原分片，**远距重放段必须重写 npz 分片**
  （6k 行 × 511×490×uint16 ≈ 3.0 GB；`np.savez` 不压缩，写入约数秒）
- 打包开销参考：26k 行 → `imgs.npy` ≈ 13.3 GB
